## 起因
这些年周旋在各种项目之间，解决和平衡各种业务逻辑和生态适配的问题，却没有时间沉下来梳理技术本身的网状结构。趁着职业gap和找寻新工作的间隙来尝试做这件事。我的学习模式属于书写适配型，所以即便用AI能生成更漂亮全面的知识博客，但为了能将知识融入到碳基脑，这里面内容将会以手写和碳基画图的方式来呈现（有些问题和理解会和AI讨论）。
